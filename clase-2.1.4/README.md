## Ejecutar el ejercicio

1. En el gestor de Godot 4.7.2, selecciona **Importar** y elige [ejercicio_presentacion/project.godot](ejercicio_presentacion/project.godot).
2. Abre el proyecto y pulsa **F5**.
3. Haz clic dentro de la ventana. Usa **WASD** o las **flechas** para mover el cuadrado y pulsa **R** para volver al centro.
